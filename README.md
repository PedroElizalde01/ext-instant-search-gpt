# ChatGPT Instant Search

A Firefox extension to quickly send prompts to ChatGPT (supports images).

## Features

- **Ctrl+Shift+Y** opens a launcher modal on any page
- Type your prompt
- Paste an image from clipboard (Ctrl+V)
- Press **Enter** → Opens ChatGPT in a new tab and auto-sends your message

## Installation

### From Firefox Add-ons (AMO)

### Manual Installation (Temporary)
1. Open Firefox → `about:debugging`
2. Click "This Firefox" → "Load Temporary Add-on"
3. Select `manifest.json` from this folder
